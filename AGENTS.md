# Fumen Language Support project instructions

## Git approval policy

Do not create a Git commit or run `git push` unless the user has explicitly
approved that exact action after the relevant changes have been presented for
review. Treat commit and push as separate approvals: approval to commit does
not authorize a push, and approval to push does not authorize a new commit.

Do not create, move, or push a release tag without the user's explicit
approval either.
