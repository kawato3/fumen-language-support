# Extension icon

The selected icon is [media/icon.png](../media/icon.png): a white F monogram
with two repeat dots on a dark blue tile.

- Selected by the project owner from three concepts.
- Created with the built-in image_gen tool using the imagegen skill.
- No upstream Fumen, VS Code or other logo image was supplied as input.
- The generated PNG is copied without visual changes: 1254 × 1254 pixels,
  with an alpha channel. VS Code scales it for display.
- Unselected concepts and the comparison page are local design drafts in
  `design/icon-options/`; they are not committed or included in the VSIX.

## Original generation prompt

```text
Use case: logo-brand.
Asset type: an original icon concept for the VS Code extension "Fumen Language Support", a lightweight text editor assistant and offline live preview for Fumen chord charts. This is an independent extension, not the official Fumen brand.
Style: exceptionally simple, flat, precise geometric logo design; confident solid shapes, balanced negative space and a strong silhouette. Make a practical software extension icon, not an illustration or a presentation board.
Composition: one centered icon on a square 1024 by 1024 canvas, occupying about 75 percent of the canvas width. A restrained rounded-square tile with a high-contrast mark inside. Keep enough padding to read cleanly at 48 pixels and 32 pixels. Choose a restrained professional two-color palette; no gradients, shadows, textures, glass, 3D or tiny decorative detail.
Do not depict a computer, screen mockup, headphones, playback controls, people or instruments. Do not copy the VS Code logo, any existing Fumen logo, or other brands. No watermark, title, labels, surrounding explanations or multiple variants.
Concept A: A custom uppercase letter "F" is the unmistakable dominant silhouette. Let the vertical stem and two horizontal arms subtly suggest the bold bar lines of a chord chart. Two small but robust repeat dots can complement the geometry, provided the F remains very clean. Prefer one memorable connected monogram over a generic music-note icon. Text allowed: exactly the single stylized capital "F"; no other lettering.
```
