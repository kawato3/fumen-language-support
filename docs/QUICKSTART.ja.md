# Fumen の入力ガイド

[English](QUICKSTART.md) | 日本語

このガイドはインストール済みの拡張に含まれているので、ネット接続なしで開けます。

以下のコマンド名は VS Code の日本語表示に合わせています。英語表示の場合はコマンドパレットで `Fumen` を検索し、`New Score`、`Insert Template`、`Open Preview to the Side`、`Open Cheat Sheet`、`Open User Guide` を使ってください。

## 1. 新しい曲を書く

コマンドパレット（macOS: `⌘⇧P`、Windows/Linux: `Ctrl+Shift+P`）で `Fumen: 新しい譜面を作成` を選びます。曲名が選択された状態になるので、入力して Tab を押します。次にアーティスト名、セクション名、小節の順に移動できます。

保存するときはファイル名を `練習曲.fumen` のようにします。保存後、右下に `Fumen` と表示されていることを確認してください。フォルダーや曲ファイルの管理には VS Code のエクスプローラーをそのまま使います。

```text
%TITLE="練習曲"
%ARTIST=""

[A]
| C | Am7 | F | G7 |
| C | Am7 | Dm7 G7 | C ||.
```

## 2. 設定や記号を補完する

- 行頭で `%` を入力すると設定名を選べます。設定は1行に1つ記述します。
- `%SHOW_STAFF=` の後では `"YES"`、`"NO"`、`"AUTO"` を選べます。
- 小節内で `<` を入力すると `<S>` や `<D.S.>` などを選べます。
- 小節内で `C:` や `r:` と入力すると音価を選べます。`4` は四分音符、`4.` は付点四分音符です。
- 候補が不要なら Escape で閉じます。コード名はそのまま手入力します。

候補が出ない場合は「候補をトリガー」コマンドで呼び出せます。通常は `Ctrl+Space` です。macOS の入力ソース切り替えと衝突する場合はコマンドパレットから実行します。

## 3. 小節を追加する

新しい行の先頭で `Fumen: ひな形を挿入` を実行し、「4小節」や「8小節」を選びます。空いている小節にコードを入力し、Tab で次の小節に進みます。Shift+Tab で前に戻れます。スニペットの編集を終えるには Escape を押します。

標準のスニペット一覧での名前や、入力して置き換える仮の文字（`Song title`、`Artist`、`annotation`、`lyrics`）は英語に統一しています。`fumen-4bars` などの接頭辞は変更していません。既存の譜面の内容を翻訳することはありません。

譜面の小節線を直接入力することもできます。1行に置く小節数は自由です。改行や空行は描画の配置に関係するため、拡張が勝手にそろえることはありません。

## 4. 説明とエラーを確認する

設定名・記号にマウスを重ねると、表示言語に合わせた説明が表示されます。詳しい記法へのリンクもあります。

設定値や閉じ忘れに問題があると波線が付きます。「表示」→「問題」でも一覧を確認できます。入力が止まって約0.7秒後に更新され、保存時にも更新されます。

これは基本チェックです。コード進行・拍数・演奏上の意味や、Fumen で必ず描画できるかまでは検証しません。

## 5. 編集しながら楽譜を見る

`.fumen` を開いた状態で、エディター右上のプレビューボタンを押します。コマンドパレットの `Fumen: 横にプレビューを開く` でも開けます。

右に楽譜が表示されます。左で入力すると、入力が止まって約0.3秒後に更新されます。保存前の変更も反映されるため、毎回保存する必要はありません。

- 「＋」「−」で拡大・縮小し、「幅に合わせる」で元の自動サイズに戻せます。
- 入力途中で描画できない場合は、前回の正常な楽譜を残し、上部に理由を表示します。直すと自動的に最新の表示へ戻ります。
- プレビューは開いた曲に固定されます。別の曲を見るときは、そのファイルからプレビューを開き直します。
- プレビューのタブを閉じると描画を停止します。再びボタンを押せば開けます。
- 元の文書を閉じた場合や、保存・名前変更で元の文書が置き換わった場合も、プレビューを開き直してください。

本家 Fumen 1.3.3 を同梱しており、ネット接続やフォントの追加インストールは不要です。既定の用紙設定は A4 で、`%PARAM` の指定があればそちらを優先します。表示の拡大・縮小では入力内容を変更しません。

長い楽譜では更新に時間がかかる場合があります。10万文字・100ページ・1回の描画につきページ画像の合計3,200万画素を上限とし、極端な描画設定も制限しています。文字計測用のキャッシュには別途1,600万画素の上限があり、%PARAM の text_size や pixel_ratio の変更で上限に達した場合は、プレビューを閉じて開き直してください。プロセス全体のメモリー量や実行時間の上限を保証するものではありません。楽譜のクリック編集、PDF 出力、左右のスクロール同期はありません。

## 6. 記法をすぐに調べる

エディター右上の本のボタン、またはコマンドパレットの `Fumen: チートシートを開く` で、[日本語のチートシート](CHEATSHEET.ja.md)を横に開けます。

VS Code の表示言語が日本語なら日本語版、それ以外なら英語版を開きます。メニュー・設定の説明・補完やホバーの説明・診断・プレビューの操作表示も同じ方針です。OS の言語や譜面の内容から推測しません。表示言語の変更後は VS Code を再起動してください。

各チートシートの先頭のリンクで、英語・日本語を切り替えられます。英語版の VS Code のまま日本語版を読むこともできます。リンクで切り替えても VS Code 自体の表示言語は変わりません。コマンドから開き直したときは再び表示言語に従います。

小節線、繰り返し、音価、注記・歌詞、曲名や表示設定を一覧で確認できます。記法の例をコピーして原稿に使えます。ネット接続は不要です。詳細は一覧内のリンクから公式資料を開けます（公式サイトの閲覧にはネット接続が必要です）。

同じコマンドを再び実行すると、既に開いたチートシートのタブを表示します。右側に楽譜プレビューがある場合は同じ場所の別タブになるので、タブで切り替えてください。ほかの Markdown ファイルを編集してもチートシートの表示内容は変わりません。

## 7. キーだけで呼び出す

横にプレビューを開く操作には、標準の Markdown と同じ既定キーがあります。Fumen の本文にカーソルがある状態で使います。

- macOS: `⌘K` を押してキーを離し、続けて `V` を押す。
- Windows/Linux: `Ctrl+K` を押してキーを離し、続けて `V` を押す。

これは順番に押す操作です。2回目の `V` では ⌘／Ctrl を押しません。

チートシート・ひな形・新しい譜面などには、好きなキーを自分で追加できます。

1. 「キーボード ショートカット」を開きます。macOS は `⌘K` → `⌘S`、Windows/Linux は `Ctrl+K` → `Ctrl+S` です。こちらは2回目も修飾キーを押します。
2. 検索欄に `Fumen` と入力します。
3. 「Fumen: チートシートを開く」など、設定したいコマンドをダブルクリックします。
4. 割り当てたいキーを押し、Enter で確定します。
5. 同じキーが既に使用されているという表示が出たら、既存の割り当てを確認し、必要に応じて別のキーを選びます。

既定のプレビューキーも、この画面で変更・削除できます。利用者のキー設定が優先されるので、拡張を更新しても自分の設定を使えます。拡張側は個人のキー設定ファイルを書き換えません。

探しにくい場合は、検索欄に `@command:fumen.openCheatSheet`（チートシート）または `@command:fumen.openPreview`（楽譜プレビュー）と入力します。

[VS Code 公式のキー設定の説明](https://code.visualstudio.com/docs/configure/keybindings)

## 8. 更新・取り外し

Marketplace 版の更新は、VS Code の拡張機能パネルで管理できます。ローカル版を更新する場合は、同パネルの `…` →「VSIX からのインストール…」で新しい `.vsix` ファイルを指定します。再読み込みの案内が出たら、未保存の変更を保存してから実行してください。

以前のローカル版 `fumen-local.fumen-language-support` が残っている場合は、先にアンインストールし、現在の `kawato3.fumen-language-support` と二重に動かないようにしてください。

取り外す場合は拡張機能一覧で `Fumen Language Support` を探し、歯車メニューから無効化またはアンインストールします。作成済みの `.fumen` ファイルはそのまま残ります。

## うまく動かないとき

- 色が付かない場合: ファイルの拡張子が `.fumen` か、右下の言語が `Fumen` か確認します。
- コード名の候補が出る場合: 設定で `wordBasedSuggestions` を検索し、Fumen の設定やほかの拡張が上書きしていないか確認します。
- 記号を打っても候補が出ない場合: 設定の `editor.suggestOnTriggerCharacters` がオフになっていないか確認します。手動の「候補をトリガー」も試せます。
- 診断が不要な場合: 設定で `Fumen` を検索し、`Diagnostics: Enabled` をオフにします。
- プレビューが更新されない場合: 上部のメッセージを確認します。入力途中の記述を直しても進まなければ、プレビューの「再読み込み」を押します。
- プレビューボタンがない場合: 更新後にコマンドパレットの `Developer: Reload Window`（開発者: ウィンドウの再読み込み）を実行します。未保存の変更は先に保存してください。
- チートシートを開けない場合: VS Code 標準の「Markdown Language Features」が無効になっていないか確認します。開けないときの案内にある「公式ページを開く」から、ブラウザーで確認することもできます。
- プレビューのキーが効かない場合: Fumen の本文をクリックしてから、順番にキーを押します。「キーボード ショートカット」で同じキーへの割り当ても確認してください。
