## 基本形と改行

```fumen
%TITLE="練習曲"
%ARTIST=""

[A]
| C | Am7 | F | G7 |
| C | Am7 | Dm7 G7 | C ||.

[B]
| F | G7 | C | C ||.
```

- `[A]`、`[サビ]` などを小節の外に書くと、セクションの見出しになります。
- 小節線で囲んだ部分が1小節です。小節内に複数のコードを書けます。
- 通常は原稿の1行が楽譜の1段になります。空行はブロックの区切りや配置にも関わります。
- 新しいセクションを別の段にしたいときは、直前に空行を入れます。空行なしの見出しは前の段に続けて配置されることがあります。
- 行頭の `<` は左寄せ、`>` は右寄せです。本家の描画では、直前の通常の段より小節数が少ない段に使います。

[公式の構造の説明](https://hbjpn.github.io/fumen/structure/)

## コード・音価・休符

| 記述例 | 意味 |
| --- | --- |
| `C`、`Am7`、`Cm7-5#11` | コード名。詳しい表記は公式のコード説明を参照。 |
| `C/D` | 分数コード。ベース音を `/` の後に指定。 |
| `/D` | ベース音だけを指定。 |
| `(4/4)` | 拍子記号。小節内に記述。 |
| `C:4` | コードと四分音符の音価。五線とリズムスラッシュを表示。 |
| `C:4.` | 付点四分音符。`C:4..` は複付点。 |
| `:4` | コード名を省略し、音価だけを指定。 |
| `C:4~ :4` | `~` で次のリズムスラッシュへタイを結ぶ。 |
| `C:4_3 :4_3 :4_3` | 四分音符の3連符。`_5`、`_6`、`_7` も指定可能。 |
| `<:16 C:2` | 後続のコードを十六分音符分シンコペーションさせる。 |
| `r:4`、`r:4.` | 四分休符、付点四分休符。休符には音価を付ける。 |
| `-2-` | 2小節の長休符。数字で小節数を指定。 |

音価の数字: `1`＝全音符、`2`＝二分音符、`4`＝四分音符、`8`＝八分音符、`16`＝十六分音符、`32`＝三十二分音符、`64`＝六十四分音符。

音価の指定だけを書く方法、タイ、連符の説明はコード／リズムスラッシュ用です。休符へ同じように適用できるとは限りません。

```fumen
[リズム]
| (4/4) C:4 :4 G7:4 :4 | Am7:2 r:2 |
| C:4~ :4 F:2 | G7:1 ||.
```

[公式のコード説明](https://hbjpn.github.io/fumen/chord/) · [音価の説明](https://hbjpn.github.io/fumen/duration-indicator/) · [休符の説明](https://hbjpn.github.io/fumen/rest/)

## 小節線・繰り返し

| 記述 | 意味 |
| --- | --- |
| `\|` | 通常の小節線。 |
| `\|\|` | 複縦線。 |
| `\|\|.` | 終止線（後ろの線が太い）。 |
| `\|\|:` | 繰り返しの開始。 |
| `:\|\|` | 繰り返しの終了。 |
| `:\|\|x3` | 繰り返し回数を3回と表示。 |
| `:\|\|xX` | 回数を X と表示。 |
| `:\|\|:` | 繰り返しの終了と開始を兼ねる小節線。 |
| `[1.]`、`[2.]` | 小節内に置くと1番・2番括弧。`[2-3.]` などの文字も指定可能。 |
| `./.` | 1小節のリピート記号（シミーレ）。 |
| `.//.` | 2小節のリピート記号。 |
| `./\|/.` | 小節線に重なるリピート記号。 |

```fumen
[A]
||: C | Am7 | [1.] F | G7 :||
>| [2.] F | C ||.
```

角括弧は位置で意味が変わります。小節の外の `[A]` は見出し、小節内の `[1.]` は繰り返しの括弧です。

<a id="signs"></a>

## 演奏記号

小節内に記述します。

| 記述 | 意味 |
| --- | --- |
| `<S>` | セーニョ。 |
| `<Coda>` | コーダ。 |
| `<to Coda>` | コーダへの移動指示。 |
| `<D.S.>` | ダルセーニョ。 |
| `<D.S. al Coda>` | ダルセーニョ・アル・コーダ。 |
| `<D.S. al Fine>` | ダルセーニョ・アル・フィーネ。 |
| `<D.C.>` | ダカーポ。 |
| `<D.C. al Coda>` | ダカーポ・アル・コーダ。 |
| `<D.C. al Fine>` | ダカーポ・アル・フィーネ。 |
| `<Fine>` | フィーネ。 |

`<S2>`、`<Coda2>`、`<to Coda2>`、`<D.S.2>` のような番号付き記号もあります。詳しい組み合わせは[公式の演奏記号の説明](https://hbjpn.github.io/fumen/repeat-sign/)を参照してください。

<a id="text"></a>

## 注記・歌詞・空白

| 記述例 | 表示位置・用途 |
| --- | --- |
| `"文字"` | コードと同じ高さのテキスト。 |
| `'注記'` | 小節のコード領域の上に表示。小節内で左寄せ。 |
| `'小さく'@ C7` | 直後のコードの上に注記を結び付ける。 |
| `` `歌詞`@ C7 `` | 直後のコードの下に歌詞を結び付ける。バッククオートを使用。 |
| `,` | コード1個分程度の横方向の空白。 |

```fumen
[A]
| 'ゆっくり' C | '小さく'@ G7 |
| `歌詞`@ C | C "rit." ||.
```

注記も楽譜に表示される内容です。プログラミング言語のコメントアウトとは異なります。

[公式のテキストの説明](https://hbjpn.github.io/fumen/text/)

<a id="settings"></a>

## 曲名・表示設定

`%名前=値` の形で、1行に1つ記述します。値は JSON 形式です。文字列はダブルクオートで囲みます。大文字・小文字を区別します。

| 記述例 | 意味 |
| --- | --- |
| `%TITLE="曲名"` | 曲名。 |
| `%SUB_TITLE="サブタイトル"` | サブタイトル。 |
| `%ARTIST="アーティスト"` | アーティスト名。 |
| `%KEY="C"` | 元のキー。短調の例は `"Gm"`。 |
| `%TRANSPOSE=2` | 半音2つ上へ移調。負の整数なら下へ移調。 |
| `%TRANSPOSE="D"` | 移調先のキーを文字列で指定。 |
| `%KEY_TYPE="b"` | 移調時の表記。`"b"`＝フラット、`"#"`＝シャープ、`"AUTO"`＝自動。 |
| `%SHOW_STAFF="YES"` | 五線を表示。`"NO"`＝非表示、`"AUTO"`＝必要に応じて表示。 |
| `%SHOW_FOOTER="NO"` | フッターを非表示。`"YES"`＝表示（本家の既定）。 |

`SHOW_STAFF` を省略した場合も自動表示です。`AUTO` の説明は Fumen 1.3.3 の実装に基づきます。移調は元の `%KEY` と併せて指定してください。

[公式の変数の説明](https://hbjpn.github.io/fumen/variable/) · [移調の説明](https://hbjpn.github.io/fumen/transpose/)

`%PARAM` は JSON オブジェクトです。用紙サイズ、文字サイズ、余白など、本家 Fumen の描画設定については、[公式 API リファレンスの RenderParam](https://hbjpn.github.io/fumen/api_reference/#renderparam)を参照してください。この拡張の既定は A4 で、極端な描画設定には制限があります。

## 拡張固有の小節番号

これは同梱レンダラーの独自機能であり、本家 Fumen 1.3.3 の機能ではありません。
別の Fumen 環境で同じ表示を得るには、対応するレンダラーパッチが必要です。

```fumen
%PARAM={"bar_number":"on"}
[A]
||: C | G |
| Am | F :||
| C | G ||.
```

各段の先頭に順に `1,5`、`3,7`、`9` と表示します。原稿上の固定番号ではなく、
**繰り返しを含む演奏順の小節番号**です。見出しのない段にも、先頭小節線の左側に
小さい文字で表示します。Chrome の印刷・PDF 出力にも反映されます。

- **`bar_number` の既定値は `"off"`。** 文字列 `"on"` の場合だけ表示します。`"off"` または省略で
  非表示になります。途中で非表示にしても、番号はリセットしません。
- **`bar_start` の既定値は `1`。** 曲頭の PARAM で開始番号を指定します。
  例えば、アウフタクト（弱起）を `0` として数えたい場合に使えます。
  負数を含む整数を指定でき、不正な値や安全に扱える整数範囲外の数値は `1` になります。
  曲頭で一度だけ適用し、途中のセクションや繰り返しで番号をリセットする設定ではありません。
- セクション・ページをまたいで数えます。弱起も1小節です。
  長休符 `-4-` は4小節分として数え、表示するのは休符の開始番号だけです。
- 通常の繰り返し、数値の `xN`、数値の反復括弧・範囲、D.S.／D.C.、Fine、Coda を
  反映します。D.S.／D.C. で戻った後は繰り返しを省略し、最後の括弧を通ります。
  `<S with repeat>` なら、そのセーニョへ戻った後も繰り返します。
- 回数未定の `xX` に到達すると採番を終了します。確定済みの番号は残し、
  それ以降の周回・小節には採番しません。回数を仮定することはありません。
- 自由文の括弧、曖昧・不整合な反復、移動先がない・重複するジャンプ、矛盾する
  演奏指示では採番を止めます。反復の途中へ戻る `with repeat` は非対応です。
  処理が10,000ステップに達した場合や、整数を正確に扱える範囲を超える場合も停止します。
- 停止の説明はプレビュー・印刷画面のステータスに表示し、譜面自体は表示・印刷できます。
  停止前の番号も、その時点で確定した周回分だけです。極端に長い番号列は余白から
  はみ出すことがあります。

弱起を小節番号 `0` とする例です。

```fumen
%PARAM={"bar_number":"on","bar_start":0}
| C:4 |
| F:1 | C:1 ||.
```

各段の先頭は `0`、`1` になります。既に PARAM がある場合は、その JSON に
`bar_start` を追加してください。この項目だけでは小節番号の表示は有効になりません。

## 拡張固有のコード構成要素表示

**この節は Fumen Language Support が加えた独自機能の説明です。公開済みの Fumen 1.3.3 の文書やパラメーターには含まれません。** この拡張に同梱するレンダラーは、下表の `%PARAM` の項目に対応しています。同じ描画パッチを適用していないほかの Fumen アプリケーションや公式のブラウザー版は、これらを無視して通常のコード表示をすることがあります。コードの記法や音楽上の意味は変わらず、変わるのは見た目だけです。省略した項目には下表の既定値が使われます。この拡張固有の表示を使わない環境へ渡すときは、これらの項目を削除してください。

本家 Fumen の標準的なコンパクト表示では、ルート音だけを通常サイズとし、その後に続くコード構成要素を小さくして上または下に配置します。短調の既定の記号はエンダッシュ（`–`、U+2013）、明示的な長調の記号はギリシャ大文字のデルタ（`Δ`、U+0394）です。白三角の `△` ではありません。この拡張では、元のコンパクト表示を明示的に保つことも、`Am7` や `AM7` のように通常サイズ・同じ基準線で表示することもできます。

| `%PARAM` の項目 | 既定値と効果 |
| --- | --- |
| `minor_label` | **既定: `"–"`** — 短三和音に使う文字。一般的な `Am` 表記にするには `"m"`。 |
| `major_label` | **既定: `"Δ"`** — 明示的な長三和音に使う文字。一般的な `AM7` 表記にするには `"M"`。 |
| `diminished_label` | **既定: `"O"`** — ディミニッシュの丸として描く大文字の O。度記号ではありません。`"dim"` にすると `Cdim`・`Cdim7` を文字で表示します。 |
| `half_diminished_label` | **既定: `"Ø"`** — ハーフディミニッシュの `m7-5` 全体に代わる文字。`"m7-5"` にすると、入力が `Cm7-5` でも `Cm7b5` でも `Cm7-5` と表示します。`minor_label` とは独立した設定です。 |
| `augmented_label` | **既定: `"+"`** — オーギュメントに使う文字。`"aug"` にすると、入力が `Caug` でも `C+` でも `Caug` と表示します。 |
| `chord_suffix_style` | **既定: `"compact"`** — Fumen 本来の小さな上付き・下付き風の配置を保つ。`"inline"` — ルート音の後の要素をすべて通常サイズ・同じ基準線で表示する。 |

次の形で指定すると、すべての既定値を明示し、本家 Fumen の元の見た目を再現できます。

```fumen
%PARAM={"minor_label":"–","major_label":"Δ","diminished_label":"O","half_diminished_label":"Ø","augmented_label":"+","chord_suffix_style":"compact"}
| Am7(#11)/C | AM7/E | Cdim7 | Cm7-5 | Caug | C+ |
```

文字によるコード表記を通常サイズで表示するには、各ラベルを選び、配置を `"inline"` に切り替えます。

```fumen
%PARAM={"minor_label":"m","major_label":"M","diminished_label":"dim","half_diminished_label":"m7-5","augmented_label":"aug","chord_suffix_style":"inline"}
| Am7(#11)/C | AM7/E | Cdim7 | Cm7-5 | Caug | C+ |
```

これらは **コードの種類ごとに表示を統一する設定であり、入力した綴りをそのまま再現するモードではありません**。例えば `augmented_label` を `"aug"` にすると、`C+` と入力しても `Caug` と表示します。`b5`・`#5` の扱いやシャープ・フラットの音楽記号は変わりません。`CØ`・`C°` といった入力記法も増えませんので、ソースでは引き続き `Cm7-5`・`Cdim` と書いてください。移調、音価、追加の変化音、オンコードは従来どおり機能します。

ラベルは文字列で指定します。文字列以外を指定した場合は既定値を使います。ハーフディミニッシュのラベルは一つの文字列として扱うため、`"compact"` でも `"m7-5"` 全体が同じ大きさ・基準線に並び、`-5` だけを上付きにはしません。すべての種類のラベルはコンパクト表示では小さくなりますが、`"min"`・`"maj"` を含め、複数文字を記号 1 文字分の幅に押し込みません。インライン表示ではオーギュメントのラベルを数字の前に置き、`Caug7`・`C+7` の順で表示します。

`"inline"` は意図的に 1 つの切替です。コードの性質、`7` などのテンション、変化五度、`#11`・`b9` などの変化音、括弧、右側に置く `/C` のようなオンコードまで、ルート音に続く要素すべてに一貫して適用します。上付き用・下付き用に分けた設定はありません。Fumen 既存の `on_bass_style` を `"below"` にした場合は、ベース音は指定どおり下に残りますが、文字サイズは `inline` の通常サイズになります。
