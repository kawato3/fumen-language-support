## 基本形と改行

```fumen
%TITLE="練習曲"
%ARTIST=""

[A]
| C | Am7 | F | G7 |
| C | Am7 | Dm7 G7 | C ||.

[B]
| F | G7 | C | C ||.
```

- `[A]`、`[サビ]` などを小節の外に書くと、セクションの見出しになります。
- 小節線で囲んだ部分が1小節です。小節内に複数のコードを書けます。
- 通常は原稿の1行が楽譜の1段になります。空行はブロックの区切りや配置にも関わります。
- 新しいセクションを別の段にしたいときは、直前に空行を入れます。空行なしの見出しは前の段に続けて配置されることがあります。
- 行頭の `<` は左寄せ、`>` は右寄せです。本家の描画では、直前の通常の段より小節数が少ない段に使います。

[公式の構造の説明](https://hbjpn.github.io/fumen/structure/)

## コード・音価・休符

| 記述例 | 意味 |
| --- | --- |
| `C`、`Am7`、`Cm7-5#11` | コード名。詳しい表記は公式のコード説明を参照。 |
| `C/D` | 分数コード。ベース音を `/` の後に指定。 |
| `/D` | ベース音だけを指定。 |
| `(4/4)` | 拍子記号。小節内に記述。 |
| `C:4` | コードと四分音符の音価。五線とリズムスラッシュを表示。 |
| `C:4.` | 付点四分音符。`C:4..` は複付点。 |
| `:4` | コード名を省略し、音価だけを指定。 |
| `C:4~ :4` | `~` で次のリズムスラッシュへタイを結ぶ。 |
| `C:4_3 :4_3 :4_3` | 四分音符の3連符。`_5`、`_6`、`_7` も指定可能。 |
| `<:16 C:2` | 後続のコードを十六分音符分シンコペーションさせる。 |
| `r:4`、`r:4.` | 四分休符、付点四分休符。休符には音価を付ける。 |
| `-2-` | 2小節の長休符。数字で小節数を指定。 |

音価の数字: `1`＝全音符、`2`＝二分音符、`4`＝四分音符、`8`＝八分音符、`16`＝十六分音符、`32`＝三十二分音符、`64`＝六十四分音符。

音価の指定だけを書く方法、タイ、連符の説明はコード／リズムスラッシュ用です。休符へ同じように適用できるとは限りません。

```fumen
[リズム]
| (4/4) C:4 :4 G7:4 :4 | Am7:2 r:2 |
| C:4~ :4 F:2 | G7:1 ||.
```

[公式のコード説明](https://hbjpn.github.io/fumen/chord/) · [音価の説明](https://hbjpn.github.io/fumen/duration-indicator/) · [休符の説明](https://hbjpn.github.io/fumen/rest/)

## 小節線・繰り返し

| 記述 | 意味 |
| --- | --- |
| `\|` | 通常の小節線。 |
| `\|\|` | 複縦線。 |
| `\|\|.` | 終止線（後ろの線が太い）。 |
| `\|\|:` | 繰り返しの開始。 |
| `:\|\|` | 繰り返しの終了。 |
| `:\|\|x3` | 繰り返し回数を3回と表示。 |
| `:\|\|xX` | 回数を X と表示。 |
| `:\|\|:` | 繰り返しの終了と開始を兼ねる小節線。 |
| `[1.]`、`[2.]` | 小節内に置くと1番・2番括弧。`[2-3.]` などの文字も指定可能。 |
| `./.` | 1小節のリピート記号（シミーレ）。 |
| `.//.` | 2小節のリピート記号。 |
| `./\|/.` | 小節線に重なるリピート記号。 |

```fumen
[A]
||: C | Am7 | [1.] F | G7 :||
>| [2.] F | C ||.
```

角括弧は位置で意味が変わります。小節の外の `[A]` は見出し、小節内の `[1.]` は繰り返しの括弧です。

<a id="signs"></a>

## 演奏記号

小節内に記述します。

| 記述 | 意味 |
| --- | --- |
| `<S>` | セーニョ。 |
| `<Coda>` | コーダ。 |
| `<to Coda>` | コーダへの移動指示。 |
| `<D.S.>` | ダルセーニョ。 |
| `<D.S. al Coda>` | ダルセーニョ・アル・コーダ。 |
| `<D.S. al Fine>` | ダルセーニョ・アル・フィーネ。 |
| `<D.C.>` | ダカーポ。 |
| `<D.C. al Coda>` | ダカーポ・アル・コーダ。 |
| `<D.C. al Fine>` | ダカーポ・アル・フィーネ。 |
| `<Fine>` | フィーネ。 |

`<S2>`、`<Coda2>`、`<to Coda2>`、`<D.S.2>` のような番号付き記号もあります。詳しい組み合わせは[公式の演奏記号の説明](https://hbjpn.github.io/fumen/repeat-sign/)を参照してください。

<a id="text"></a>

## 注記・歌詞・空白

| 記述例 | 表示位置・用途 |
| --- | --- |
| `"文字"` | コードと同じ高さのテキスト。 |
| `'注記'` | 小節のコード領域の上に表示。小節内で左寄せ。 |
| `'小さく'@ C7` | 直後のコードの上に注記を結び付ける。 |
| `` `歌詞`@ C7 `` | 直後のコードの下に歌詞を結び付ける。バッククオートを使用。 |
| `,` | コード1個分程度の横方向の空白。 |

```fumen
[A]
| 'ゆっくり' C | '小さく'@ G7 |
| `歌詞`@ C | C "rit." ||.
```

注記も楽譜に表示される内容です。プログラミング言語のコメントアウトとは異なります。

[公式のテキストの説明](https://hbjpn.github.io/fumen/text/)

## 曲名・表示設定

`%名前=値` の形で、1行に1つ記述します。値は JSON 形式です。文字列はダブルクオートで囲みます。大文字・小文字を区別します。

| 記述例 | 意味 |
| --- | --- |
| `%TITLE="曲名"` | 曲名。 |
| `%SUB_TITLE="サブタイトル"` | サブタイトル。 |
| `%ARTIST="アーティスト"` | アーティスト名。 |
| `%KEY="C"` | 元のキー。短調の例は `"Gm"`。 |
| `%TRANSPOSE=2` | 半音2つ上へ移調。負の整数なら下へ移調。 |
| `%TRANSPOSE="D"` | 移調先のキーを文字列で指定。 |
| `%KEY_TYPE="b"` | 移調時の表記。`"b"`＝フラット、`"#"`＝シャープ、`"AUTO"`＝自動。 |
| `%SHOW_STAFF="YES"` | 五線を表示。`"NO"`＝非表示、`"AUTO"`＝必要に応じて表示。 |
| `%SHOW_FOOTER="NO"` | フッターを非表示。`"YES"`＝表示（本家の既定）。 |

`SHOW_STAFF` を省略した場合も自動表示です。`AUTO` の説明は Fumen 1.3.3 の実装に基づきます。移調は元の `%KEY` と併せて指定してください。

上級設定の `%PARAM` は JSON オブジェクトです。例えば次の指定で用紙幅と高さを変更できます。拡張のプレビューには極端な画像寸法を防ぐ上限があります。

```fumen
%PARAM={"paper_width":800,"paper_height":1100}
%TITLE="用紙設定の例"

[A]
| C | Am7 | F | G7 ||.
```

[公式の変数の説明](https://hbjpn.github.io/fumen/variable/) · [移調の説明](https://hbjpn.github.io/fumen/transpose/) · [描画パラメーター](https://hbjpn.github.io/fumen/api_reference/)
